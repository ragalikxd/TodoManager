# TodoManager

Консольное приложение для управления списком задач, написанное на Python.

## О проекте

TodoManager позволяет создавать, просматривать и управлять списком задач прямо из терминала. Все данные сохраняются в формате JSON, поэтому задачи не теряются после завершения программы.

Проект был создан в учебных целях для практики работы с функциями, словарями, JSON-файлами и системой контроля версий Git.

## Возможности

- Добавление новых задач
- Просмотр списка задач
- Отметка задачи как выполненной
- Удаление выбранной задачи
- Очистка всего списка задач
- Автоматическое сохранение задач в файл tasks.json

## Запуск проекта

1. Клонирутей репозиторий:

```bash
git clone https://github.com/ragalikxd/TodoManager.git
```

2. Перейдите в файл проекта:

```bash
cd TodoManager
```

3. Запустите программу:

```bash
python main.py
```
